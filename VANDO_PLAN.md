# Вандо 2.0 — ИИ команды, который делает, а не только говорит

Роч, 29.10.2026: «улучши чат Вандо, доведи до абсолюта, додумай, как это должно работать в команде».

## Что сейчас (замер по коду)
- Личный чат на одном устройстве: история в localStorage (`cockpit_vando`), на другом устройстве её нет.
- Каждый вопрос шлёт в ИИ весь снимок проектов (до 60 КБ JSON) — `vandoContext()` index.html, `mode:'chat'` supabase/functions/ai-review.
- Отвечает только текстом: ничего не делает, не ссылается на задачи/клиентов, не помнит договорённостей команды.
- Одинаков для всех ролей: участник видит в ответах деньги и CRM так же, как владелец.
- Модель claude-sonnet-4-6.

## Как должно работать в команде (принципы)
1. **Предлагает действие — человек жмёт «Применить».** Ответ = текст + карточки действий (перенести, назначить,
   создать задачу, отложить, сдвинуть этап клиента, черновик сообщения клиенту). Ничего не делает сам; всё с «Вернуть».
   Удаление ИИ не предлагает вообще.
2. **Говорит объектами.** Каждая задача/клиент/человек в ответе — живая ссылка (открыть карточку), а не просто слово.
3. **Память команды, приватный разговор.** Разговор — личный (как личка). Но «Запомни: клиенты платят до 5 числа» → в память
   проекта (её видит вся команда и сам Вандо в следующих ответах). Ответ можно «Отправить в команду» — комментарием к задаче
   или в Telegram-выжимку.
4. **Видит ровно то, что видишь ты.** Контекст — только доступные тебе проекты; участнику без прав на деньги — без сумм и CRM.
5. **Знает, где ты.** Подсказки зависят от экрана: на «Клиентах» — «Кто остывает?», на «Неделе» — «Разложи неделю»,
   в карточке задачи — «Разбей на шаги / Кому отдать?».
6. **Голос и Telegram — тот же Вандо.** Микрофон в поле ввода (есть dictateTo), в боте — «спроси Вандо» тем же движком.
7. **Честность.** Нет данных — говорит «не знаю, вот что нужно заполнить»; цифры — только из данных; «думал N с» вместо
   фальшивых этапов.

## Реализация
**Фронт (index.html):**
- Панель Вандо: шапка с переключателем «Проект / Вся компания», лента сообщений, карточки действий (Применить · Изменить · Нет),
  ссылки-объекты `[[task:ID]]` / `[[client:ID]]` → чипы, «Запомнить» и «Отправить в команду» на ответе, микрофон,
  подсказки по экрану, «думал N с» (think-shimmer ROCH Motion), мобайл — полноэкранная шторка.
- Контекст: id задач/клиентов (для ссылок и действий), роль пользователя, фильтр денег/CRM для участников, сжатие (открытые задачи
  целиком, закрытые — счётчиком), текущий экран.
- Исполнитель действий: whitelist {move_date, assign, create_task, snooze, set_status, crm_stage, crm_next, remember}
  → существующие editTaskInProject / addTaskToProject / quickAssign / crmSetStage; каждое — с «Вернуть».
- История: локально + опционально синк в облако только своей строкой (нужна таблица с RLS «только владелец» — миграция).

**Сервер (supabase/functions/ai-review, mode 'chat'):**
- Модель → claude-sonnet-5-5; ответ — текст + блок `actions` (JSON-схема, tool use), ссылки `[[task:ID]]`.
- Системный промпт: роль «вице-фаундер», правила честности, запрет действий без подтверждения, язык — русский, коротко.
- Лимиты/биллинг — как сейчас (FREE_MODES, учёт usage).
